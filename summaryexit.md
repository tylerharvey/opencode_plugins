Write a handoff summary of this session so the work can be resumed cheaply in a fresh session, then stop.

1. Create or update a file named after the current session (the exact session name and ID are appended below) as `<session_name>_to-be-continued.md` in the current working directory.
2. The summary must contain:
   - What was being worked on and why
   - Current state: what is done and verified, what remains
   - Concrete next steps for resuming
   - Key files, commands, flags, and gotchas needed to continue
3. Be concise but complete enough that a new session can pick up without re-reading the transcript.
